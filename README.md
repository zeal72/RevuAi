# RevuAi

> An AI-powered review management platform built for hospitality 
> managers. Collect guest reviews, surface insights with AI analysis, 
> and get clear recommended actions — all in one dashboard.

## Live Demo
[RevuAi](https://revu-ai-sage.vercel.app)

## The Problem
Hospitality managers deal with reviews scattered across Google, 
TripAdvisor, and Booking.com. Reading them manually is slow. 
Knowing what to actually fix is harder. RevuAi solves both.

## What It Does
- Aggregates and displays guest reviews in one dashboard
- Uses AI to analyse sentiment and identify recurring issues
- Surfaces prioritised, actionable recommendations for managers
- Saves hours of manual review reading every week

## Built With
- React + Vite
- JavaScript
- AI integration for sentiment analysis and recommendations
- Tailwind CSS

## Run Locally
git clone https://github.com/zeal72/RevuAi
cd RevuAi
npm install
npm run dev
